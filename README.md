# IAL | International Association League

Одностраничный сайт лиги — чёрно-белая тема, экран загрузки, плавающий фон с абстрактными иконками (кубок, медаль, щит, звезда), расписание матчей, правила, статистика игроков и история чемпионов.

## 📁 Структура (всё в корне, без подпапок)

```
.
├── index.html
├── favicon.png
├── .nojekyll
├── .gitignore
└── README.md
```

## 🚀 Деплой на GitHub Pages

1. Создай репозиторий → залей `index.html`, `favicon.png`, `.nojekyll` (Add file → Upload files, всё в корень)
2. **Settings → Pages → Source:** branch `main`, папка `/ (root)` → Save
3. Через минуту сайт будет на `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/`

## ✏️ Как редактировать контент

Весь контент — в массивах в конце `index.html`, внутри `<script>`:

**Расписание матчей** — массив `MATCHES`:
```js
{ home:"Команда А", away:"Команда Б", date:"12.08", time:"20:00", status:"upcoming" },
```
`status` может быть `"upcoming"`, `"live"` или `"finished"`.

**Правила** — массив `RULES`:
```js
{ title:"Заголовок правила", text:"Описание правила" },
```

**Статистика игроков** — массив `PLAYERS` (сейчас пустой, заполняй сам):
```js
{ rank:1, name:"Игрок", club:"Клуб", apps:10, goals:8, assists:4 },
```

**Чемпионы** — массив `CHAMPIONS`:
```js
{ season:"Сезон 20", club:"Название клуба" },
```

## 🖼️ О плавающих иконках

В фоне летают абстрактные иконки кубка/медали/щита/звезды вместо реальных фотографий игроков — так безопаснее с точки зрения авторских прав и приватности (фото конкретных людей без их явного согласия на использование в фоне сайта лучше не размещать). Если хочешь заменить иконки на что-то своё — ищи блок `FLOATING CHAMPION ICONS` в конце `index.html`.
